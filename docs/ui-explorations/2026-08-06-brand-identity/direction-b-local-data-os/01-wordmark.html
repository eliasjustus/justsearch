01 — Mark & wordmark

The Chamber & the Return

The mark is not about searching. Searching is the commodity. The mark is about the boundary the search never crosses — so it is drawn as an enclosure with a return path sealed inside it.

A

The mark

Construction — 64u grid

  • Wall5u stroke, 13u corner radius, unbroken
  • Clearance≥ 12u on every side — the return never touches the wall
  • Return5u stroke, butt caps, mitred joins, 45° head
  • Clear space1 wall-stroke (5u) on all sides, minimum

A carriage return, sealed in a chamber. The query goes in, the answer comes back, and neither leaves the machine — the loopback drawn as a shape. It is a keyboard glyph every engineer already reads as "run this", set inside a wall every lawyer reads as "closed". No lens, no magnifier, no beam: the differentiator is containment, not lookup.

B

UI variant — block cursor as the brand's full stop

Monospace, weight-split. The wordmark is set in the same face the product prints its evidence in — mono is the voice of a thing that shows its work, and using it in the logotype means the brand and the log line are the same typeface. Just is 700, Search is 400: the emphasis lands on the word carrying all three readings — merely, simply, and just as in justice — while "Search" stays plain, because searching is the part everyone already has. Tracking is pulled to −0.035em so the mono grid reads as a designed word, not a terminal echo.

The cursor is punctuation, not decoration. A steady teal block after the wordmark is the one moving element in the whole identity, and it only appears in live surfaces — app chrome, hero, docs. It never ships inside the static logo files, so the mark survives print, favicons, and greyscale untouched.

C

Registers

Dark — primary. Wall #EAECEF, return #00CCB2

Light — wall #0E1013, return steps down to #00655B

Single-colour — engraving, laser, stencil, 1-bit

The return can drop to the wall's colour without losing the idea; the wall can never drop out. If only one element survives a reproduction, it is the enclosure.

D

Misuse

  • Neverbreak the wall, gap it, or let the return cross or touch it
  • Neveradd glow, bloom, gradient fill, or a second accent hue
  • Neverrotate the mark or mirror the return
  • Neverset the wordmark in a proportional face
  • Neveranimate the mark — the cursor is the only thing that moves
