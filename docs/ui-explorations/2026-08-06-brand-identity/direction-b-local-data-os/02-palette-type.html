02 — Palette & type

One accent, five greys, no glow

The app already had this palette; it was spending it on atmosphere. Here the neutral ramp does the layout work, teal is rationed to exactly one job — this is live, local, and yours — and the three status hues never appear outside status.

Five greys, one step apart. Every elevation in the product is a single ramp step plus a 1px rule — no blur, no shadow, no translucency doing structural work. Glassmorphism survives in exactly one place (the command bar's scrim over scrolling results), where it is texture, not identity.

D

Typography — two voices

Voice 1 · utility & display

JetBrains Mono

400 / 500 / 700. Wordmark, every label, every value, every path, every citation, every code sample. Rendered here in the system mono fallback.

  • Display 700JustSearch
  • Head 700 / 22Cited, on device
  • Value 400 / 13D:\Kanzlei\Mandate\2019\Rahmenvertrag.pdf
  • Label 500 / 10Index · loopback · sources

Why mono carries the brand. It is the typeface of things that can be checked — a path, a hash, a port number, a page cite. A product whose whole argument is "verify it yourself" should be set in the face that makes verification legible.

Voice 2 · prose

Segoe UI Variable / system-ui

400 / 600. Sentences a person reads for meaning: hero copy, help, explanations, answer text. Deliberately the platform's own face — it should feel like Windows, not like a website.

  • Lede 400 / 21Your own messy files
  • Body 400 / 15Cited answers, in 70+ languagesAA 7.5:1
  • Small 400 / 13Supporting detail and captions
  • Strong 600 / 15Provable, not promised

The split is a rule, not a preference. If a string is something the machine knows, it is mono. If it is something a person is being told, it is sans. Nothing sits in both — that boundary is why mono never tips into "hacker terminal".

Setting: mono tracks −0.02em at display sizes and +0.14em uppercase at 10px labels; sans runs 1.6 line-height and never exceeds 64ch. Sentence case everywhere; uppercase is reserved for micro-labels, where it functions as an instrument legend.

E

Light & dark strategy

Light register — derived, not designed separately

Dark is the origin. The product ships dark and the brand is authored there; light is a strict inversion of the neutral ramp only — hairline weights, spacing, ramp steps and the teal's job stay identical, and the only value that changes is the teal itself, stepping down to #00655B so the accent carries the same contrast rather than the same brightness.
