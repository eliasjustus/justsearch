SHEET 02/05 — PALETTE & TYPE

Four papers, three inks, one signal.

Light-first: the working surface is enamel white, the way lab equipment and technical drawings are. Depth comes from a step in surface value and a hairline — never from a shadow, a blur, or a glow. Colour is not decoration here; it is either structure (ink on paper) or function (one accent for interaction, three for status). Nothing else is allowed to be coloured.

Light and dark

Light is the design; dark is a strict inversion of it. The same four surface steps, the same hairline logic, the same single accent held at one hue and chroma and lifted in lightness only — oklch(51.9% 0.168 37) becomes oklch(66.3% 0.166 43) — so dark mode is a lighting condition, not a second brand.

Light — default

Enamel white, graphite ink. The unusual choice for a developer tool, and the deliberate one: a near-white app reads as instrument, not as terminal — which is what the lawyer, the therapist and the journalist need to see.

Dark — same instrument, night lighting

Surfaces get lighter as they rise, exactly as in light mode. Still no blur, still no glow — the hairline does the work at #34383C.
