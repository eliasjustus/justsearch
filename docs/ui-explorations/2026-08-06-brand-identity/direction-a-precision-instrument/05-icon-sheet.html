SHEET 05/05 — ICON SHEET

One path. No hinted variants.

Outlined icons die at 16 px; a mass does not. The mark is a solid chamfered body with a datum bar and two rules cut out of it, drawn on a 32-unit field using even coordinates only — so at 16 px every edge lands on a whole device pixel, and the same single path is used from the favicon to the installer tile.

Reversed cut — installer tile and dark surfaces

Rule

The tile takes the same chamfer as the mark, at the same angle and the same proportional size — the container and the thing it contains are cut by the same tool. The mark itself is never tinted: it is ink on paper, or paper on ink. There is no coloured app icon.

No half pixels anywhere, at any standard size: every number in that column is an integer at 16 px, and doubles cleanly at 32, 64, 128 and 256. The design was adjusted to make that true rather than described as if it were — the outer wall moved from 3 units to 2 so the silhouette lands on a pixel edge too.
