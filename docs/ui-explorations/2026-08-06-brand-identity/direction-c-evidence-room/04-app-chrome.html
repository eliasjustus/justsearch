What changed

The rail carries the volume. Dark binding on the left, paper everywhere else — the product’s two facts (bound, kept) stated by the layout before any copy is read.

Rank is a real number, so it sits in the margin. Numbering appears here only because order carries information; nothing else in the identity is numbered for effect.

Provenance is typeset, not badged. Paths and page numbers are set in mono beneath each entry — checkable, quiet, and never dressed as a terminal.

Oxblood means one thing. It marks the matched passage and the citation, and it is the only saturated colour in the window.
