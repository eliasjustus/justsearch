Palette & typography

Colour comes from the physical archive, not from a UI kit: laid paper, iron-gall ink, oxblood buckram binding, ledger green. The palette has one accent and it means one thing — oxblood marks a citation. Nothing else is allowed to use it.

Light / dark strategy: light is the default because this is a reading product — dark is the same page after hours, so the two modes swap ground and ink but keep identical structure, rule weights and accent semantics, and the accents are re-mixed for lightness rather than reused, so every pairing clears WCAG AA in both.

The sans never sets a sentence. It labels, and it stops — which keeps the serif’s voice unmistakably the product’s voice.

Mono is reserved for things a reader could go and check: file paths, page numbers, the bound address. It is provenance, not decoration — which is why it never reads as a terminal.

In use The footnote rule is one third measure, set solid ink — print convention, kept.
