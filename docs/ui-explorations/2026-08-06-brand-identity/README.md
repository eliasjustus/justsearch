# 2026-08-06 — Brand identity round 1

**Theme:** first brand/visual-identity exploration (mark, wordmark, palette, hero, app-chrome
tinting) — *brand*, not UI-direction, so this round deviates from the folder convention:
each direction ships five self-contained **HTML cards** instead of `rationale.md` + PNGs
(rationale text is embedded in the cards). The cards are also mirrored to the founder's
claude.ai/design project **"JustSearch Brand Explorations"** for browsing.

## Contents

- `brief.md` — the commissioning brief (approved copy, honesty constraints, hard constraints).
- `direction-{a-precision-instrument,b-local-data-os,c-evidence-room,d-sovereign}/` — four
  parallel directions, five cards each (wordmark, palette+type, hero, app-chrome, icon sheet).
- `mark-comparison/00-mark-comparison.html` — all five candidate marks under identical neutral
  conditions (96/32/16 px, light/dark, source-color + monochrome, taskbar strip).
- `mark-e-claude/01-claude-mark.html` — a fifth mark designed after reviewing A–D.
